qconform
========

A vendor-neutral conformance checker for pulse-level quantum control.

Given a pulse program and a device's declared capabilities, decide whether the
program is realizable on that device. Design-time, deterministic. No runtime,
no hardware ownership.

Status: early. Nothing functional yet.
